API 키는 정리하고,
이름은 의미 있게.

TXT에서 API 키를 읽고, KEY_NAME은 공식·통용 기관 약칭을 최우선으로 사용하고, 기능명은 짧은 영어 의미어로 바꿉니다. API_KEY까지 포함해 최대 5토큰으로 압축하며, 로마자 표기는 약칭이나 번역어를 찾지 못했을 때만 마지막 fallback으로 사용합니다. 파일과 인증키는 서버로 전송하지 않고 현재 브라우저 안에서만 처리합니다.
